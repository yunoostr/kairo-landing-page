# Desk Demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A click-to-play, voiced macOS desktop demo under the hero where Claude Code, a GitHub PR and Slack open in cascade and Kairo's pill floats over each.

**Architecture:** One client component (`components/demo.tsx`) renders a 16:10 desktop whose every element derives from a single `phase` string plus a tick counter `n`. A content module (`components/demo-content.ts`) holds the five texts, the ordered phase list, how each phase ends, and a pure `advance()` function that the scheduler and the tests share. Two effects drive it: an interval that bumps `n` while a phase streams or sweeps, and a timer/audio effect that calls `advance()` when the phase ends.

**Tech Stack:** Next 16 / React 19, Tailwind v4 + tw-animate-css (already installed), Tabler icons, `node --test` for the pure logic, Playwright (cached by npx, see memory) for the visual check. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-09-04-desk-demo-design.md`

## Global Constraints

- No new dependency. `ShaderBackground`, `Reveal`, `wordEnds`, tw-animate-css classes and the `eq` keyframes are reused as is.
- Achromatic only: colors come from the tokens in `app/globals.css` (`bg-card`, `bg-secondary`, `bg-primary/75`, `text-muted-foreground`, `border-border`) plus `#0d0d0d` for the desktop ground and `#3a3a3a` for the traffic-light dots.
- Word lamp is `bg-primary/75 text-background`; selection is `bg-white/[0.13] text-foreground`; both exactly as in `components/hero.tsx`.
- Stream cadence 28 ms per word, sweep cadence 22 ms per word (the site's existing numbers).
- Everything inside the desktop is sized in `cqw`/`em`/`%` so it scales with the frame. No mobile-specific layout.
- `prefers-reduced-motion: reduce` renders the `slack-listen` layout statically, no button, no audio.
- ESLint runs `eslint-plugin-react-hooks` v7: never call a setState synchronously in an effect body. State resets go through the state object, media queries through `useSyncExternalStore`.

// each phase ends. Kept apart from the component so the TTS command and

export const PLAN =
  "Migrate session handling from JWT cookies to server-side sessions stored in Redis. The refresh endpoint goes away. `auth/middleware.ts` reads the session id from the cookie and loads the user once per request. Existing tokens stay valid for 24 hours so nobody gets logged out during the rollout."

export const PR_BODY =
  "This PR replaces the JWT cookie flow with server-side sessions. Every request used to verify a signed token and, when it was close to expiry, call the refresh endpoint to mint a new pair, which meant two round trips on a cold tab and a race when two tabs refreshed at once. Sessions now live in Redis with a 30-day sliding TTL, the middleware loads the user once per request, and the refresh endpoint is deleted. Old tokens are accepted for 24 hours after deploy so nobody is logged out."

export const PR_SUMMARY =
  "Done: JWT cookies replaced by Redis sessions, refresh endpoint removed. Changed: `auth/middleware.ts`, the session store, login and logout routes, one migration. Left to decide: the 30-day TTL, and whether to keep the 24-hour token grace after the first deploy."

export const SLACK_FR =
  "Salut, j'ai relu la PR des sessions ce matin. Le middleware me paraît propre, mais je ne suis pas sûr du TTL de 30 jours : pour les comptes admin on avait dit 7 jours max. Tu peux confirmer avant que je valide ? Sinon je merge cet après-midi."

export const SLACK_EN =
  "Hi, I reviewed the sessions PR this morning. The middleware looks clean, but I'm not sure about the 30-day TTL: for admin accounts we said 7 days max. Can you confirm before I approve? Otherwise I'll merge this afternoon."

export const spoken = (text: string) => text.replaceAll("`", "")

export const PHASES = [
  "rest",
  "claude-open",
  "claude-stream",
  "claude-select",
  "claude-shortcut",
  "claude-read",
  "pr-open",
  "pr-shortcut",
  "pr-summarize",
  "pr-replace",
  "slack-open",
  "slack-shortcut",
  "slack-translate",
  "slack-listen",
  "end",
] as const
export type Phase = (typeof PHASES)[number]

const words = (s: string) => s.split(" ").length

// Milliseconds between ticks while a phase streams (28) or sweeps (22).
export const TICK: Partial<Record<Phase, number>> = {
  "claude-stream": 28,
  "claude-select": 22,
  "pr-open": 22,
  "pr-summarize": 28,
  "slack-open": 22,
  "slack-translate": 28,
}

// How a phase ends: after N ms, when its audio ends, or on a click.
export const ENDS: Record<Phase, number | "audio" | "click"> = {
  rest: "click",
  "claude-open": 500,
  "claude-stream": words(PLAN) * 28 + 400,
  "claude-select": words(PLAN) * 22 + 500,
  "claude-shortcut": 700,
  "claude-read": "audio",
  "pr-open": words(PR_BODY) * 22 + 900,
  "pr-shortcut": 700,
  "pr-summarize": words(PR_SUMMARY) * 28 + 800,
  "pr-replace": 900,
  "slack-open": words(SLACK_FR) * 22 + 900,
  "slack-shortcut": 700,
  "slack-translate": words(SLACK_EN) * 28 + 800,
  "slack-listen": "audio",
  end: "click",
}

export function advance(
  phase: Phase,
  event: "click" | "timer" | "ended"
): Phase {
  const end = ENDS[phase]
  const ok =
    end === "click"
      ? event === "click"
      : end === "audio"
        ? event === "ended"
        : event === "timer"
  if (!ok) return phase
  return phase === "end" ? "claude-open" : PHASES[PHASES.indexOf(phase) + 1]
}

// Words revealed one by one: the first `shown` exist, the first `selected`
// are swept, `current` is lit by the lamp. `code` words keep their backticks
// in the source and render as inline code.
function Words({
  text,
  shown = Infinity,
  selected = 0,
  current = -1,
  caret,
}: {
  text: string
  shown?: number
  selected?: number
  current?: number
  caret?: boolean
}) {
  const words = text.split(" ")
  const n = Math.min(shown, words.length)
  return (
    <>

export function Demo() {
  // One state object so a phase change resets the tick counter in the same render.
  const [s, setS] = useState<{ phase: Phase; n: number }>({ phase: "rest", n: 0 })
  const [current, setCurrent] = useState(-1) // word being read
  const audio = useRef<Record<string, HTMLAudioElement | null>>({})
  const reduced = useSyncExternalStore(
    subscribe,
    () => matchMedia(REDUCED).matches,
    () => false
  )
  const go = (phase: Phase) => setS({ phase, n: 0 })
  const click = () => go(advance(s.phase, "click"))

  // Streaming and sweeping read from one counter that restarts every phase.
  useEffect(() => {
    const ms = TICK[s.phase]
    if (!ms) return
    const id = setInterval(() => setS((x) => ({ ...x, n: x.n + 1 })), ms)
    return () => clearInterval(id)
  }, [s.phase])

  // Timed phases end on a timeout, audio phases on `ended`. A phase whose
  // file never plays (blocked, missing) still ends after 25 s.
  useEffect(() => {
    const phase = s.phase
    const end = ENDS[phase]
    if (end === "click") return
    if (typeof end === "number") {
      const id = setTimeout(() => go(advance(phase, "timer")), end)
      return () => clearTimeout(id)
    }
    const el = audio.current[phase]
    const ends = wordEnds(AUDIO[phase]!.text.split(" "))
    const onTime = () =>
      el && setCurrent(ends.findIndex((e) => el.currentTime / (el.duration || 1) < e))
    const done = () => {
      setCurrent(-1)
      go(advance(phase, "ended"))
    }
    el?.addEventListener("timeupdate", onTime)
    el?.addEventListener("ended", done)
    el?.addEventListener("error", done)
    el?.play().catch(done)
    const id = setTimeout(done, 25_000)
    return () => {
      clearTimeout(id)
      el?.removeEventListener("timeupdate", onTime)
      el?.removeEventListener("ended", done)
      el?.removeEventListener("error", done)
      if (el) {
        el.pause()
        el.currentTime = 0
      }
    }
  }, [s.phase])

  // With reduced motion the desk is a still of beat 3.
  const p: Phase = reduced ? "slack-listen" : s.phase
  const n = reduced ? Infinity : s.n
  const i = PHASES.indexOf(p)

        {!reduced && is("rest", "end") && (

            className={cn(

            )}
          >

          </div>
        )}
      </Reveal>
    </section>
  )
}
